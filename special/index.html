패키지 구매 시 드리는 진도표 엑셀

교재 패키지 · 올인원을 구매하시면 진도표 엑셀 파일을 함께 드려요. 입력 칸만 바꾸면 회차별 날짜 · 수업 내용 · 숙제가 자동으로 채워져요.

사용법 영상 1분 15초 · 소리를 켜고 보세요 · 전체 화면으로 보기 ↗
1 2 3 4
  1. 수업 설정 학년 · 시작 날짜 · 총 회차 · 주 수업 횟수 · 수업 시간을 넣어요. 칸을 누르면 ▼ 목록에서 골라요.
  2. 교재 선택 쓸 교재는 O, 안 쓸 교재는 X. 고른 교재를 번갈아 섞어 배분해요.
  3. 자동 계산 필요한 시간 · 추천 회차를 보여 주고, 회당 시간이 넘치면 빨갛게 알려 줘요.
  4. 회차별 진도표 날짜 · 수업 내용 · 숙제가 채워져요. 휴강일을 넣으면 다음 수업일로 넘어가요. 그대로 인쇄해서 쓰세요.
고쳐 쓰기 · 되돌리기쓰기 전에 파일을 복사해서 사본으로 작업하세요. 원본을 남겨 두면 언제든 처음 상태로 돌아갈 수 있어요.모든 칸은 직접 고쳐 쓸 수 있어요. 칸을 한 번 누르고 바로 입력하면 바뀌어요(여러 줄은 Alt + Enter).처음 상태로 돌리려면 Ctrl + Z, 또는 받은 파일을 다시 열거나 카카오톡 플러스친구로 요청해 주세요.
